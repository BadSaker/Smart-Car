# 当前控制档位与复现

当前采用2026-10-14运动稳定性软件交付，完整结果与限制见[交付报告](../../outputs/reports/motion-stability-2026-10-14.md)。正式源码参数由[自动驾驶指南](../../docs/autonomous-driving.md)维护；本页维护仿真分档及验收方法，仿真通过不代表实车已验证。

当前完整验证_800为800/800/800/800；完整验证_1000为1000/900/800/800；完整验证_1200为1200/900/800/800。高档PWM1000‰、横向加速度限2400mm/s²；默认低档分别400‰、2000mm/s²。仿真选择不会回写固件参数。

验收同时要求完整指定路线、实际里程0.8–1.1圈、全RUNNING阶段零撤PWM、无故障、四轮角点余量非负、路径Q裕量至少10。起步只豁免最低速度要求；正常最低速度采用min(800,四档最小值)的98%。另检查共同转向及单轮目标/PWM斜率。旧理想模型仅作对照，不能满足本轮独立轮速验收。

无界面复现，在Autodrive根目录执行：

```powershell
python -B simulation/tools/validate_control.py `
  --config simulation/configs/中速验证_300.json `
  --output tmp/control-check/default --directions AB BA
```

可以添加`--disturbance 2 --seed 7`或`--offset 0.03 --heading 5`。输出含C源码副本、构建指纹、SHA256、全程遥测、状态事件、轨迹和汇总。检查`pass_run`，不能仅看车辆仍在运动或行驶里程。

当前中央270°环形路段能循迹通过，但局部图像无前向分叉，入口仍标为弯道；右侧360°环岛的进出状态链已双向验证。350mm/s只针对当前未标定模型，不能代表实车3.6m/s能力。完整限制、数据和固件验证见[最终验收报告](../../outputs/reports/control-tuning-final-2026-10-12.md)。
