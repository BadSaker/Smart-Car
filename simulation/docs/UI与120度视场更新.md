# UI与120度视场更新

2026-10-11，按用户“修改Ui和参数”直接授权执行。文件全部在simulation，Autodrive只读。

- 启动默认hfov=120°，不再由defaults()的两点拟合覆盖成104.1288°；俯角保留39.436814°。四个内置配置均改120°并保留各自俯角。旧130度标称文件改名为标称相机20度_120度假设.json。
- 镜头视场角按用户最新要求改为普通数值输入框，移除下拉选项，默认120°，接受20～165范围内的自定义数值，包括小数。修改后应用并重置。保存JSON并重新读取仍保留自定义值。
- 主状态区按名称和数值排列，保留状态、时间、距离、车速、转角、横向偏差、路径可信度、元素和故障。近远场误差、外侧支持、轮速、PWM、舵机脉宽等移入可开关的诊断窗口，窗口实时更新且不挤压主界面。
- 参数区按名称/数值/单位三列显示，车体及相机位置使用mm，响应/步进时间使用ms；内部计算和JSON保留原SI单位。未改动的字段保持完整原值，避免将显示位数截断当作参数变更。
- 删除横幅和画面中重复的实现说明与“xx·xx”式副标题；近似尺寸和校准限制仍在项目文档中记录。
- 两组页签采用自定义平面背景，选中或悬停只改变颜色，不改变padding、字体、边框、expand及尺寸。tools/check_ui_120.py逐一切换两组所有页签并模拟鼠标按下/释放，检查实际命中矩形完全一致。
- 故障模拟三个选项改为单行并列，给状态区留出空间。

验证报告为reports/ui-120-checks.json，实际Tk截图为reports/ui-120-camera.png与ui-120-status.png。备份为backups/before-ui-120deg-20261011.zip。镜头度数属于仿真水平视场参数；更改视场不等同实际相机内参标定，也不意味着修复实车停车。
