# 参数、界面与扰动

当前内置预设从`configs`读取，外部参数登记使用被Git忽略的`parameter_locations.local.json`。项目内登记可为相对simulation的路径，外部路径仅本机有效。外部同名预设带“外部”标记，不覆盖内置参数。失效路径提示；取消另存不产生文件。禁止覆盖car源码、参考及原始SeekFree资料。

## 配置职责

活动配置只枚举`configs/*.json`，不递归读取子目录。保留以下11份配置，不以当前内容相同作为删除用户参数入口的依据。

| 配置 | 用途 |
| --- | --- |
| 完整验证_800 / 1000 / 1200 | 新独立轮速模型条件验证：800四档相同；1000/1200仅提升直道，弯道900、外侧/元素800；未实车标定 |
| 默认_完整赛道_C算法 | 当前300/250/220/220、PWM400的默认完整赛道基线 |
| 实测基线_350_350_350_250 | 历史实测参数快照，保留原字节；不代表当前固件控制参数 |
| 低速验证_180 | 低速native控制器验证 |
| 中速验证_300 | 中速native验证，扰动幅度较默认配置大；0级时扰动关闭 |
| 我的参数 | 用户编辑入口；保留原速度与相机数据，同步已确认舵机端点和新运动控制，可独立修改 |
| 提速验证_350 | 提速验证，不代表已标定的实车能力 |
| 完整赛道_理想几何参考 | 理想参考控制器对照，不计为C视觉算法通过 |
| 中期区段_完整背景 | 中期区段场景验证 |

历史配置保存在`configs/archive/`：`标称相机20度_120度假设.json`和`历史_297mm_53度.json`。它们用于历史复现与相机对照，不是当前标定结果；原JSON内容不变。相机对齐脚本的默认`--before`读取后者，`--after`仍读取活动的`我的参数.json`。归档文件仍可用`parameters.load`或CLI显式路径加载。

## 参数操作

选择参数后应用并重置，再启动。JSON中几何长度用m、目标速度用mm/s；元素速度和PWM上限确实映射到C宏。旧配置缺字段时沿用100mm/s元素速度及200‰PWM，不悄悄升级旧实验。

历史250档说明：当时正式源码、默认参数和实测基线曾统一为350/350/350/250mm/s。用户已反馈250档编译、烧录及实测通过；本轮另完成参数映射、GUI加载/重置、双向整圈与扰动验证，详见[完整配置报告](../../outputs/reports/config250-2026-10-13.md)。其余验证档与“我的参数”保持。工具栏倍率为现实时间中的目标推进率，旁边显示实测倍率；高倍率绘图降频，控制步长与相机仿真采样率保持。暂停、重置、最小化清除调度积压；恢复后不会补跑隐藏期间的时间。检查入口tools/check_speed_ui.py覆盖完整赛道事件循环、倍率与轨迹一致性、切换、暂停、重置、最小化恢复和回放。双线性图像合成的C实现与NumPy参考逐像素核对，模型参数保持。

扰动分0至4级，默认0。固定seed用于复现，自动种子需记录实际值；偏移、航向、亮度和灰度噪声的等级定义见perturbation.py。扰动运行和关闭扰动的确定性基线分别验收。

相机标定保留297mm输入高度，以六行参考拟合未知俯角和有效视场；先计算候选，再应用。改动输入使旧候选失效。当前模型31.46896度/89.66951度为条件拟合，镜头120度标称定义未知，详见[camera-alignment](camera-alignment.md)。

2D、3D、车模和摄像头视图支持窗口缩放；跟车为观察视图，不改变控制状态。参数精度由原值保存，界面显示精度不用于截断模型输入。历史界面更新见[归档](archive/UI与120度视场更新.md)。

2026-10-14同步10份非历史活动预设的1330–1630µs、±34.74318°、20µs步进、共同运动约束及独立轮速模型；“实测基线_350_350_350_250”和archive内JSON原字节保持，历史预设不代表当前固件。新增“运动”“动力”页可调轨迹、单轮目标斜率、PID跟踪及未标定的动力参数。速度无500上限，仍拒绝非法或超出C float范围输入。图像延迟0–500ms、模糊0–3px保持。当前结果见[报告](../../outputs/reports/motion-stability-2026-10-14.md)。
