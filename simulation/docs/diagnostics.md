# 停车、回放与实测对照

原生控制状态、故障、路径接受原因以C输出为依据；GUI诊断包含独立显示判断，不能将路径支持度Q解释为统计概率。停车锁存首次停止证据，保留前5秒与后2秒帧及路径数组，导出后检查采集是否完成。

原始帧回放只接受188×120图像，没有同步里程输入；因此不能复现依赖里程的完整元素过程。实测对照可导入原始帧或完整逐飞截图，彩线和文字覆盖区掩码显示，不能恢复被覆盖像素，也不自动改变车辆姿态。

地面点坐标以后轴为原点，CSV字段x_mm,y_mm,u_px,v_px。相机标定的数据冲突、固定高度约束和截图独立配准边界见[camera-alignment](camera-alignment.md)。原始八图保留在`../assets/measurements`，文件SHA-256在正式交付报告中记录。

截图对照的图像重合度不证明估计车姿正确，不代表已完成实车相机或动力学标定。原交付过程见[历史诊断](archive/停车诊断与实测对照.md)。
