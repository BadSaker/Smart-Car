# 小车仿真实验室

2026-10-12相机修正已应用。实测尺寸固定为镜头高度 **297 mm**、镜头位于前轴后 **110 mm**（后轴前80 mm）、道路内宽 **500 mm**。当前默认和“我的参数”的俯角 **31.46896°**、有效水平视场 **89.66951°**是六行宽度的条件拟合，**不是实测角度**。用户所述镜头“120°畸变角”单独保存为标称信息，方向定义仍未知。

本地Tk桌面程序提供2D赛道、3D场景、C1车模、188×120摄像头、现有C算法闭环、图像回放和实测对照。主工程 `../car/` 本轮未改动。详细依据见 [相机修正说明](docs/camera-alignment.md)，结果见 [验证报告](../outputs/reports/camera-alignment-2026-10-12.md)。

## 启动和配置

关闭旧仿真窗口后，双击 **启动仿真.cmd**。默认参数已更新，也可以在左侧“选择参数”中选“我的参数”。修改输入后点击“应用并重置”，再点击“启动/继续”。

- 启动入口仍为 `.cmd → launch.ps1 → start_app.py`，自动寻找64位Python和Tkinter/NumPy/Pillow，不自动安装依赖。
- “我的参数”、默认完整赛道、理想几何参考和中期区段配置采用本轮相机条件模型。控制器参数未改。
- `configs/历史_297mm_53度.json` 保留修正前配置及原有3级扰动；原“标称相机20度”配置保留作历史假设对照。
- 新默认关闭扰动，使用2×2像素积分及双线性栅格采样，便于重复比较。需要随机试验时可在“扰动”菜单选择等级。
- “相机标定”页可选择采样方式；旧配置缺少采样字段时继续使用单点最近邻。所有合法组合保存、读取和重置都保持一致。
- 黑边宽度允许0：表示不绘制额外黑带，不表示已经测得外宽。道路灰度255、背景153来自截图亮度近似，不等同真实曝光模型。

本机本轮验证：Python3.14.6、NumPy2.4.6、Pillow12.3.0。实际环境以 `reports/launcher-runtime.json` 为准；其他电脑可使用符合 `requirements.txt` 的环境。

## 相机标定和实测对照

标定保持输入的镜头高度和道路内宽，拟合未知俯角及有效水平视场。先计算候选，再主动应用；参数变化后旧候选失效。不相容的数据会报错，不会通过改变高度掩盖问题。

六行参考仍为30/45/70/86/108/116行的44/59/97/120/156/167px，最大拟合误差3.27px。这组数与近直道截图中的白色真实道路轮廓不完全一致，因此界面标为“参考”。拟合依赖平地直道、主点(93,59.5)、fx=fy、无偏航/横滚/畸变假设。主点、姿态和畸变尚未实车标定。

“实测对照 → 导入帧/截图”支持：

1. 188×120原始灰度帧。
2. 左右边界完整、未改变图像纵横比例的逐飞助手截图。程序识别图像区域并近似采样，彩线/文字覆盖位置显示紫色；不能恢复被覆盖的原始像素。

截图导入不自动改变相机或车辆姿态。地面标定点以后轴为原点，x向前、y向左，单位mm；CSV为 `x_mm,y_mm,u_px,v_px`。完整截图不能作为无损原始帧直接送入“图像回放”。回放仍只接受188×120原始帧，且没有同步里程输入。

## 控制与场景边界

“现有C算法”使用 `vendor/` 中的应用源码副本和 `native_bridge.c`，首次使用新的C参数时生成独立DLL。“理想几何参考”读取赛道真值，不能把它的成功算作现有视觉算法通过。

使用10ms控制周期、低速自行车运动学；舵机最大前轮转角28°、电机增益/死区和响应时间仍是假设。完整赛道按原图拓扑重建，包含约221.57mm的未标注闭合连接段；参考路线约30.021m，不是现场实测圈长。A/B标线不进入摄像头。

道路仍是平面栅格，尚未复现墙面、人物/杂物、地面接缝、阴影、真实曝光和轮胎动力学。图像轮廓改善不表示已经完成物理相机标定或实车完赛验证。

## 复现检查

在项目根目录使用本机已验证解释器运行（其他机器替换解释器路径）：

```powershell
& 'D:\anaconda3\python.exe' -B -m unittest discover -s simulation/tests -p 'test_*.py' -v
& 'D:\anaconda3\python.exe' -B simulation/tools/check_camera_alignment.py --images tmp/figs --output tmp/camera-check/alignment
& 'D:\anaconda3\python.exe' -B simulation/tools/check_camera_ui.py --images tmp/figs --output tmp/camera-check/ui
```

测试调用原生控制器时可能生成 `simulation/build/` 缓存。本轮在任务临时副本中执行，未将检查缓存混入发布源码。检查脚本的 `--output` 应使用任务临时目录；审核后的报告移入 `outputs/reports/`。

图像对照脚本为每张截图独立搜索车辆位置和方向，固定相机参数和赛道几何。输出的道路区域重合度是配准诊断，**不是已知车姿下的独立标定精度**。本批完整分辨率平均值85.95%→90.71%，7张改善、1张略降，详见报告。
