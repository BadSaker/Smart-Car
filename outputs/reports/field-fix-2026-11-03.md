# 实车反馈修订与严格/宽松按键模式（2026-11-03）

## 交付边界

本轮按用户批准实现源码修改、主机验证；用户追加要求通过主板按键切换判定标准0/1并显示，已一并接入。没有构建Keil固件、烧录或操作车辆，没有Git add/commit/push。Windows主机测试与诊断DLL编译不代表固件构建或实车通过。

源码基于HEAD 31d0bc5cae04b76046849a983722b413cd725276及本聊天上一任务的6000超速宏修改。发布HEX/BIN仍是原文件，不能将当前源码功能当作车上已有功能。

## 按键与屏幕

- 上电默认P0（严格），P1为宽松；不写Flash，重启回P0。
- C14/S3按下仍立即停车，保持约2000ms后切换P0/P1；长按只切换一次，须松开后才能再次切换。
- 上电始终按住S3不会切换，必须先释放再长按。切换保持停车，需重新按C15启动。
- C13的Wi-Fi开关、C12遥控允许、C15启停职责保持。没有使用组合键或占用C13。
- 模式由PIT内控制状态记录，主循环在非active时同步给视觉，改变模式会清除旧视觉候选；不在PIT内并发reset视觉状态。
- 第一行示例：`AUTO:RUN P1 Q78/40 V1 E1 O0-`。P0/P1即判定标准0/1；Q为控制状态/故障快照，门限依上下文变化。
- 第二行`LQ`是实时路径评分，`RQ`是实时原始观测评分；故障后仍更新这两个值，第一行故障Q和trace保留触发证据。评分不是概率，不能脱离V和拒绝原因使用。
- 标记过程中第二行保留Z、R/G、M、D，并显示LQ/RQ。受39字符限制，原N/F及S字段让位给实时Q；T/C在普通诊断行保留。该顶部文字调整为用户明确要求的屏幕冻结例外，图像区域和图传协议/发送流程没有改变。

## 两种判定模式

| 条件 | P0严格 | P1宽松 |
| --- | --- | --- |
| 普通道路控制Q | 45 | 40 |
| 可靠外侧普通弯控制Q | 40 | 35 |
| 已确认有效元素控制Q | 35 | 30 |
| 外侧近/远实测覆盖 | 70% / 50% | 60% / 40% |
| 环岛候选 | 连续3帧 | 最近3个处理帧中2票 |
| 岛边连续跨度 | 12行 | 8行 |
| 岛边凸性与连续行 | 2px / 3行 | 1px / 2行 |
| 岛边短期记忆 | 仅当前证据 | 最近150ms且100mm内，仍须当前缺口、分支、来向和可行路径 |
| 斑马线弱预告 | 不使用 | 4次稳定跳变、连续2行，仅预告 |
| 正式斑马线条纹 | 至少6次跳变、3连续行 | 同左，不靠弱预告计圈 |

| 砖候选 | 4～50行、宽度收缩至预计90%以下 | 3～50行、宽度收缩至预计94%以下 |
| 弱路径恢复 | 3个新坏帧锁存LOST | 当前近场有支持、无明确几何危险时，最多150ms/100mm；期间撤动力 |

入环提交仍保留独立连续3帧条件；环内及部分出口证据可用宽松的2帧门槛，但正式出环仍保留近场闭合、距离和恢复条件。宽松不是所有视觉条件关闭，不取消停车键、反馈失效、反号/堵转、异常硬超速或明确危险路径的停车。

外侧覆盖计数与当前实际预瞄窗口一致，避免自适应窗口改变后仍拿固定远场行数作分母。普通路速度表1200/900/800/800、PID增益、舵机中位/窗口和供应商驱动保持。

## 连续Q

原实现几何轮迹全部通过时用通过比例覆盖支持度，通常得到100；无效帧最终又清成0。现保留连续的观测/路径证据，将几何质量作为加权项：两份路径支持分、一份原始观测分、一份几何分，平均后作为控制Q。几何有效性仍单独检查；无效帧保留已获得的证据评分，不靠清零表达所有拒绝。

因此可能出现Q较高但V0/G拒绝，这表示当前图像有道路证据、所选轨迹仍未通过。不能仅凭Q继续行驶。黑白板/无对比度等没有有效证据时仍输出无效，Q为0。

## 2500可恢复轮速抑制与计距

两种模式共有：原始单轮绝对速度严格超过2500mm/s即撤该轮正向PWM，绕过正常下降斜坡；另一轮不能在抑制期间继续加力。不锁存OVERSPEED，不自动反转。

该轮回落到2200mm/s以内并完成3个新编码器采样后解除抑制；重复采样序号不计数。恢复按原PWM上升斜坡，PID按实际执行输出跟踪。最后一个恢复确认采样仍不用于计距，下一可信采样才继续累加。

超过6000mm/s仍立即撤两路PWM并锁存OVERSPEED。编码器失效、持续反号和堵转保护保持。新逻辑不能证明轮胎已经重新接地，双轮同时在2500以下打滑仍无法仅由编码器识别；这属于实测边界。

主机测试覆盖左右轮2501立即撤输出、负向越限、6000/6001边界、重复反馈不解锁、滞回恢复、里程冻结、恢复PWM不跳升、停车优先。

## 斑马线、十字与红砖

宽松模式在正式条纹区外寻找连续3行、中心可见且有真实外沿的道路锚点，并排除整行重复条纹；具备这些当前证据后，条纹区内部允许用单条真实外沿按标定宽度恢复另一侧。道路外部允许有限附加背景转换。该推断不计作双边实测；没有当前区外锚点的满屏条码不能获得此许可。

轮迹局部量化容错仅用于宽松模式：3×3邻域4个白点且中心仍白、且不在已识别砖区域时允许；真实黑块和路外继续拒绝。十字仍稳定使用来向与远端出口关联，放宽的环岛证据可在暂定十字阶段纠正身份；已确认近场十字的保护保持。

砖仍需前后道路锚点、当前空侧净宽、两帧确认和最终轮迹检查；只放宽初现行数和侵入比例，不取消净宽，也没有把砖涂白。接近底部后的已有偏移保持/回归机制保留。

曾尝试仅扩大条纹区域，回放有效路径反而减少，因此没有把它当作最终依据。最终单边恢复增加锚点约束，严格/宽松两套都通过满屏条码和黑块反例。

## 起终点与渐减速

第一次通过仍记录起点；离开后重武装，保留8秒/5000mm最小圈门槛。首次穿越仍受低速策略约束。

第二次近场确认进入FINISHING，保存当时的入口目标速度，不立即固定限到100mm/s。必须先在有效路径中看到标记末端到达至少112行，再得到连续5个有效离线新帧，才确认末端离开视野。第一次可信离线位置作为额外距离基准；条纹还在视野内的行驶距离不算入这段距离。

参考距离为1000mm。剩余距离给出`sqrt(2 * AUTO_DECEL_MM_S2 * remaining_mm)`速度上限，并与入口速度、普通路/曲率/元素限制取小；上限只下降、不因重识别抬高，继续通过既有目标和PWM斜坡。终点超时增至25秒，配置允许1～1500mm。

完成必须同时满足可信累计距离、末端离线确认、新有效图像和有效路径；冻结图像会触发原标记阶段250ms时效保护，空转样本不推进距离。终点目标速度与真实轮速不同，DONE表示撤PWM，不表示已物理停止。

参考1000mm不是规则合规保证。相机到后轴、斑马线长度、地面制动和滑移仍未实测；需要确认后轮/全车投影越线且没有超出允许停车范围。录像末端没有展示标记完全出画及后轮过线，不能完成这一实车验收。
