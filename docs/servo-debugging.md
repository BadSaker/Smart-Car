# S-U400舵机控制与校准记录

更新：2026-10-07。用户通过手动校准后明确确认中值为 **1480µs**，并要求回退到正式版本。临时校准已结束，S2一次摆动、S3停止程序作为独立测试模式保留；摆幅按已批准方案由±40µs增至 **±60µs**，端点为 **1420µs与1540µs**。

## 独立测试模式操作

当前默认为虚拟手柄遥控，S2不会触发摆动；本页按键摆动适用于`REMOTE_CONTROL_ENABLED=0`。中值1480µs和±60µs窗口保留，用户现已确认1420µs向右、1540µs向左。遥控操作见 [虚拟手柄指南](virtual-remote-control.md)。

模块为 [servo_control.c](../car/src/servo_control.c)，接口为 [servo_control.h](../car/include/servo_control.h)，参数集中在 [servo_config.h](../car/config/servo_config.h)。上电C30保持GPIO低电平，不自动输出PWM或扫舵。

| 按键 | 当前功能 |
| --- | --- |
| C15 / S2 | 稳定释放后新按下，启动一次摆动测试 |
| C14 / S3 | 优先停止PWM，并把信号脚切回GPIO低电平 |
| C13 / S4 | 原Wi-Fi软件开关，默认OFF；本次未改 |
| C12 / S5 | 当前启动/中止电机与编码器测试，不调整舵机中值 |

重新打开 [工程](../car/autocar.uvprojx)，Rebuild后由用户下载；烧录后完全断电、移除DAP排线，再用电池运行。建议首轮摆动验证保持Wi-Fi OFF，减少同步网络等待对按键响应的影响。

先松开S2、S3，再按S2约0.1–0.2秒后松开。一次测试依次执行：

1. 输出中值1480µs，保持500ms。
2. 每20ms最多改变2µs，缓慢到1420µs，保持300ms。
3. 缓慢到1540µs，保持300ms。
4. 回到1480µs并保持，等待下一次新按键事件。

及时轮询时一次完整测试约3.5秒；刷屏或网络等待可能延长时间，程序不追赶积压产生大步跳变。本车已由用户确认：减小脉宽向右，增大脉宽向左。

按住S2上电不会启动；长按S2不重复测试，测试过程中再次按S2不会排队。S2/S3同时按时停止优先。结束或停止后，必须稳定释放S2并重新按下才能再次启动。

屏幕第二行恢复`S:...`、当前命令脉宽和`S2:run S3:stop`提示，不再显示CAL。结束时DONE保持1480µs；S3停止后STOP显示0µs，表示不输出PWM。

## 参数与硬件事实

| 参数 | 当前值与依据 |
| --- | --- |
| 舵机及信号 | Futaba S-U400，主板接口1/P16，C30/PWM4_MODULE2_CHA_C30 |
| 供电 | 用户确认6.0V，配置记录为6000mV |
| PWM频率 | 50Hz |
| 中值 | 1480µs，2026-10-03由用户校准后指定 |
| 摆幅/端点 | ±60µs，1420–1540µs；扩大后的机械行程仍需实车观察 |
| 步进 | 2µs/20ms，迟到最多走一步 |
| 停留 | 初始中位500ms，两端各300ms |
| 按键消抖 | S2按下和释放均30ms；S3停止不等待消抖 |

用户保留已安装的舵盘和转向拉杆。本次确认的是用户选择的中位命令值，不是助手测得的物理角度或示波器脉宽；扩大后的端点、负载电压和机械干涉尚未由自动化工具验证。

官方 [S-U400产品页](https://www.rc.futaba.co.jp/products/detail/I00000423)中的1520µs是此前参考初值，当前本车采用用户确认的1480µs。官方 [产品目录](https://www.rc.futaba.co.jp/downloads/W9C1819N2310231413bk2in.pdf?mode=view)给出6.0–7.4V范围；软件供电配置检查不等于ADC实测保护。

[官方说明书](https://www.rc.futaba.co.jp/downloads/shop/WCI00000087N2106211007dfrhu.pdf?mode=view)说明失去输入信号仍保持。因此S3停止PWM不等于断电或卸力；若机构顶住或异常持续发力，应切断实际舵机电源。S3是软件停止键，不能作为硬件急停。

接口依据 [主板手册](<../参考/RT1064 V3.0主板硬件说明 V1.0.pdf>)及 [V3.0.1.2原理图](<../参考/RT1064主板V3.0.1.2 原理图.pdf>)，接线主记录见 [硬件与引脚](hardware-and-pins.md)。按主板手册方向摆放（电池接口在左侧），右侧拨码下四键从上到下为C15/S2、C14/S3、C13/S4、C12/S5。

## 模块调用与验证边界

主循环启动时调用一次`servo_control_init(now_ms)`，独立测试模式随后调用`servo_control_poll(now_ms)`；遥控模式使用主循环遥控目标接口。`servo_control_start_test`检查供电配置、停止键及新的消抖事件，不能直接调用以绕过物理按键。C30由本模块独占，主循环没有恢复旧循迹打角逻辑，电机上电仍关闭，C12可运行独立短时测试，见 [电机编码器指南](motor-encoder-debugging.md)。

`servo_control_get_status()`返回状态、当前/目标脉宽与输出标志。停止时两项脉宽为0；COMPLETE仍保持用户中值。临时的`calibration_pulse_us`、CALIBRATING状态和C12调节分支已撤回。

PWM换算仍使用库的`PWM_DUTY_MAX`尺度：当前10000尺度下，1480µs/50Hz对应740。2µs命令变化对应一个库占空比单位，底层整数计数还有量化误差，不能把命令值当作实测波形。

Wi-Fi默认OFF时不会等待网络；开启后的原同步连接/发送/重连可能推迟主循环读键与步进。1ms计时器不代表停止响应为1ms。本次不改变冻结的屏幕/图传/C13流程。

## 校准结束与恢复来源

临时校准阶段已结束，不再等待中值，也不再执行S2+/S5−操作。原控制器、头文件、屏幕状态栏、主循环及测试入口从 [校准前备份](../outputs/backups/car_before-servo-calibration_20261003_211213.zip)局部恢复，只更新中值1480与摆幅60。没有整体覆盖工程。

手动校准代码和固件保存在 [恢复前备份](../outputs/backups/car_before-servo-center-restore_20261003_213551.zip)，便于追溯；原临时测试文件已从活动工程移除。将来如需再次校准，应按新指令明确范围，不擅自恢复临时模式。

原生测试覆盖6组配置：默认6.0V、欠压、过压、7.4V、不同PWM尺度和非整除步长。已按1480中值与1420/1540端点更新行为预期，覆盖一次完整往返、归中保持、限幅、停止优先、消抖、长按不重复和计时回绕。结果见 [舵机回归](../logs/servo-center-restore-tests.log)、[完整回归](../logs/servo-center-restore-suite.log)、[主工程构建](../logs/servo-center-restore-build.log)及 [当日日志](../logs/2026-10-03.log)。

软件验证不代替扩大行程的实物验收，本任务没有自动烧录或驱动舵机。

2026-10-04补充：电机模块在PIT0采到S3后立即发电机零PWM命令，并锁存舵机停止请求；主循环恢复时先消费该请求再轮询舵机。舵机函数仍不在ISR调用，Wi-Fi等待仍可延后实际舵机停止。电机测试及结束5秒内顶部两行暂显示编码器，随后恢复舵机状态；中值/摆幅和舵机模块本身未改。
