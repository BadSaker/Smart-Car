## C13 Wi-Fi开关

当前默认：**上电Wi-Fi关闭，屏幕先显示摄像头图像。** C13对应S4，是主板四个按键中C15、C14下面的第三个；当前舵机使用C15/S2启动一次摆动、C14/S3停止，C12不再校准；详见 [舵机指南](servo-debugging.md)。

1. 上电先松开C13，屏幕底部显示`Wi-Fi OFF; C13:ON`。
2. 按C13约0.1–0.2秒后松开，开启Wi-Fi并使用原同步流程连接；成功后显示`Wi-Fi ON; TCP ready; C13:OFF`。
3. 再次按C13关闭。关闭后跳过Wi-Fi初始化、查询、重连和图像发送；摄像头、屏幕、图像算法和舵机按键继续执行。
4. 再次开启会复位并建立新连接，只允许新的完整图像，不续发旧半帧。TX/E/R统计保留，主动开关不算自动重连失败。

按键按下接地，上拉输入；按下和释放都需要30ms稳定采样，长按只切换一次。按住上电不会自动开启，必须先稳定释放再重新按下。电源重启后恢复默认关闭，不保存开关状态。

软件关闭通过本地B16复位引脚保持Wi-Fi模块复位实现，**不切断5V供电**，因此模块电源灯可能仍亮。该复位保持从相机初始化完成后的`camera_debug_init()`开始，不代表供电最初阶段已经被硬件强制关闭。关闭不调用阻塞式socket断开命令；电脑客户端列表可能暂留旧条目，不能单凭列表判断开关状态。重新连接后如仍选中旧客户端，选择新建立的连接。

保留同步接口的限制：正在联网、发送等待或重连时，主循环暂时不能采样C13。短按可能未被采到；可保持按下直到看到OFF，再松开。关闭真正生效后不会再执行网络等待。网络开关本身不改变舵机逻辑；舵机已另行确认1480µs中值并恢复按键摆动。

参数在`camera_debug_config.h`：`CAMERA_DEBUG_WIFI_BOOT_ENABLED=0`、`CAMERA_DEBUG_WIFI_KEY_PIN=C13`、`CAMERA_DEBUG_WIFI_KEY_ACTIVE=0`、`CAMERA_DEBUG_WIFI_KEY_DEBOUNCE_MS=30`。`CAMERA_DEBUG_ENABLED=1`表示编译图传功能，不表示上电已经联网。

| 模块 | 接口与引脚 | 供电 |

| MT9V034 | P2 CSI，使用逐飞摄像头接口 | CSI 3.3V |

## 当前代码流程

初始化屏幕与舵机安全上电状态，启动现有PIT计时和摄像头；`camera_debug_init`默认只登记边线、初始化C13并保持Wi-Fi复位，不发联网命令。

每圈主循环执行：

1. 服务当前控制状态；有相机帧时取采集时间/序号、清完成标志并复制188×120灰度。复制期间换帧则放弃混合缓冲，不按帧年龄丢弃。
2. 执行视觉算法并发布本帧摘要和边线。自动驾驶时继续服务控制，等待PIT消费本帧及舵机实际应用确认；停车解除等待。
3. `camera_debug_capture_frame`显示原始灰度并保存图传副本，再服务控制、二值化，`camera_debug_send_frame`同步发送完整协议帧。
4. 发送返回后服务控制，再调用`camera_debug_poll`处理C13和停车时的联网/恢复；非自动模式读取遥控，最后再服务控制。没有新图像也执行这些维护步骤。

屏幕为320×240横屏，原始灰度按282×180显示在(19,40)，保留宽高比。Wi-Fi发送188×120灰度和实际计算的三条边线，默认每个处理帧都尝试发送。库内部使用其原有的4088字节分块及INT就绪握手。

供应商发送函数返回未发送后缀长度；应用只重试该后缀，默认额外2次、间隔20ms。非法长度或重试耗尽后停止本帧后续块，记录失败阶段和剩余字节。

失败调用返回后，从首次poll开始等待5000ms再尝试重连。发送失败时先尝试关闭旧socket，随后硬件复位模块、重新入网和建立TCP；即使关闭失败也继续复位。新连接必须重新采集图像，不发送旧半帧。累计TX/E/R不因自动重连清零，配置错误不反复重试。

**保留开启状态的历史同步等待行为：** 开关关闭时不执行网络工作；开启但联网失败不会直接禁止预览，不过同步连接、发送和重连期间主循环会等待，屏幕可能暂停，C13和舵机按键及步进也会延后。供应商入网/TCP等待参数分别为10秒/50秒，函数可能多次等待，不能把它们当作整次恢复的严格时限。当前不保证断网时屏幕全程实时，也不为改变这一行为重新引入异步模块。

舵机配置和保持特性见 [舵机指南](servo-debugging.md)。当前C14/S3停车由10ms PIT处理电机撤输出；舵机撤输出仍需主循环返回后服务，PIT1的1ms时基不代表舵机停车响应时间为1ms。

## 屏幕状态

顶部`TX/E/R`分别是驱动接受的完整帧数、网络失败事件数和自动重连次数。TX不是电脑确认收图数量。第二行属于舵机状态栏；当前恢复`S:...`、命令脉宽和`S2:run S3:stop`提示；图像与网络显示流程未改。

| 底部状态 | 含义 |
| --- | --- |
| `Wi-Fi OFF; C13:ON` | 关闭网络，只运行本地预览；C13开启 |
| `Wi-Fi ON; initializing/reconnecting` | 已开启，正在同步初始化或重连 |
| `Wi-Fi ON; TCP connecting...` | 已开启，正在连接电脑TCP服务器 |
| `Wi-Fi ON; TCP ready; C13:OFF` | 已连接，C13可关闭；电脑收图仍以实际计数为准 |
| `Wi-Fi: check network config` | 网络参数格式或长度错误 |
| `Wi-Fi failed; waiting to reconnect` | 初始化或加入热点失败，等待下一次尝试 |
| `TCP failed; waiting to reconnect` | TCP连接失败，核对热点、电脑地址和侦听状态 |
| `TX ... rem:...; reconnect` | 某协议块发送失败，记录阶段及剩余字节后重连 |

失败阶段`head/image/b-head/left/middle/right`对应图像头、像素、边线头和三条边线。恢复历史版后不再使用异步模块的`receive`阶段提示。
