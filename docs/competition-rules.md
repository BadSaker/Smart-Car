# 竞赛规则摘要

## 来源与适用范围

本摘要依据本地 [智能车校赛规则 PDF](<../参考/智能车校赛规则 .pdf>)（东南大学第二十一届智能车校赛，v0.5，2026-09-25）及 [各组别罚时细则](../参考/各组别罚时细则.docx)。PDF 为图片型资料；本页是工程检索摘要，争议条款应回查原文并向主办方核实。

[摄像头组宣讲](../参考/智能车摄像头组宣讲.pptx) 日期为 2026-09-23，提供学习和算法建议，不能替代正式规则。罚时细则明确目前适用于资格赛，后续盲盒任务可能改动，临近预赛公布。硬件考核、奖励以及软件盲盒的未公布细节均不补写、不推断。

## 组别与摄像头赛道

组别包括摄像头组、电磁组（面向大一）和室内惯导组。项目当前主要围绕摄像头组组织应用与学习资料。

摄像头赛道使用白色 PVC、黑色边界和蓝色背景，包含直道、弯道、十字、环岛、起跑斑马线及红砖，无坡道。工程应对这些元素分别建立识别、处理和验收条件；赛道元素存在不代表已有算法实现。

- 车辆在起跑线前 1 m 内发车。
- 完成一圈后停车，全车投影须越过起跑斑马线，并停在过线后 1 m 内。
- 十字必须通过；不能以绕开十字或跳过环岛作为正常完成。

## 有效成绩与罚时

| 事件 | 判定或罚时 | 适用说明 |
| --- | --- | --- |
| 一个轮胎投影完全位于边线外 | 最多允许一个 | 镜头组、电磁组的资格赛细则 |
| 两个及以上轮胎投影完全位于边线外 | 本次成绩无效 | 电磁组红砖区段存在例外，不套用于镜头组 |
| 十字路口未通过 | 比赛失败，成绩无效 | 镜头组、电磁组 |
| 停车未完全经过斑马线或明显超出 1 m | 成绩无效 | 镜头组、电磁组 |
| 遗漏一个环岛 | +30 s | 镜头组、电磁组 |
| 行驶中撞击红砖但仍能继续前进 | +15 s | 镜头组 |
| 拿走红砖 | +30 s | 镜头组 |
| 遗漏一个锥桶 | +30 s | 惯导组 |
| 撞击锥桶但无明显位移 | +1 s | 惯导组 |
| 撞击锥桶且明显位移或撞倒 | +3 s | 惯导组；细则原文“撞到”应在有争议时回查确认 |
| 中途停止运行超过 10 s | 成绩无效 | 惯导组，不作停车要求 |

镜头组和电磁组在资格赛及预决赛应在规定的有限时间内完成发车。只调试的发车不记录成绩；需要记录时向裁判示意。最多记录 3 次有效成绩，不能主动放弃有效成绩、不能中途手动停车；无效发车不计入有效成绩次数。上场时限的具体数值和后续任务调整须以主办方公布内容为准。

## 硬件限制

| 类别 | 当前规则要点 | 对工程的影响 |
| --- | --- | --- |
| 无线通信 | 正式计时发车不能携带无线模块；调试时允许 | 图传和无线调参属于调试能力，正式发车前按规则移除模块 |
| 模块中的 MCU | 模块不得含 MCU，核心板及规则允许情形例外 | 核对模块实物及电路，不能仅凭营销名称判定 |
| 摄像头 | 不允许 K230、OpenMV 等带处理核心的摄像头方案 | 使用符合规则的采集方案，在核心 MCU 上处理图像 |
| IMU | 不得带 MCU | 核对传感器板是否包含额外处理器 |
| 编码器 | 支持正交或方向编码器；不允许成品磁编码器或电机内置高精度编码器 | 确认型号、信号方式和安装来源后再配置测速 |
| 惯导组定位 | 仅 IMU 与编码器，不允许 GPS、RTK、UWB | 不将外部定位方案作为惯导组实现路径 |
| 自制 PCB | 表面铜层须有学校、队名、日期，小于 1 cm² 的板豁免；赛后提交源文件 | 保留 PCB 设计源文件，设计时核对标识要求 |
| 车模与电机 | 指定车模 380 电机；B/C/F 为建议车模，也允许自制 | 实物车模与电机仍需确认，不能由参考图推定 |
| 电池与负压 | 一组电池，允许负压 | 实车设计与供电配置按该限制核对 |

## 实施与验收记录

设计起跑和停车逻辑时，将“识别斑马线”“越线”“全车投影越线”“1 m 内停止”分别验证；仅识别到斑马线不足以证明停车合规。环岛、十字与障碍处理应保留测试场景和结果，最终验收结合实车轨迹与裁判规则。

宣讲建议采用灰度采集、二值化、边线提取、元素状态机和闭环控制；其舵机位置式 PID、电机增量式 PID 等是教学建议，不是竞赛强制要求。可根据实车验证选择算法，不能宣称建议参数已适配当前车辆。

主办方更新规则时，记录新版本和日期，比较受影响条款，同步本页、硬件配置与相关验收条件；具体工作按 [workflow.md](standards/workflow.md) 审核执行。
