## 按键和模式

| 当前模式 | C12 | C13 |
| --- | --- | --- |
| OFF | 连接并开启WAVE | 连接并开启IMAGE |
| WAVE | 关闭Wi-Fi | 重建连接并切到IMAGE |
| IMAGE | 重建连接并切到WAVE | 关闭Wi-Fi |

- 上电默认OFF。C15仍为自动驾驶启停，C14仍为优先停车。
- C12不再允许虚拟手柄、执行台架测试或取消自动驾驶。正式工程移除了遥控源文件引用与主循环调用。
- 只在控制状态非行驶时切换；行驶中按下不会排队。停车后必须全部释放至少30ms，再按目标模式键。长按只触发一次，双按忽略，上电按住不触发。
- PIT只记录行驶代次，确保同步图传阻塞期间发生过行驶，也会撤销旧按键资格。联网、复位和发送仍在主循环。
- 模式切换会硬复位模块并建立新TCP连接；必须选择助手里的新客户端。关闭保持模块复位，不切断5V供电。
- IMAGE只发送灰度及边线；WAVE只发送八通道波形。WAVE/OFF仍采集相机、执行视觉与控制并保留本地屏幕预览。

## 采集空转异常

1. 停车，电脑开启当前配置的2.4GHz热点。逐飞助手选“网络 → TCP Server”，使用现有图传IP和端口（项目记录192.168.137.1:8080），开启侦听。
2. 助手切到“示波器”，关闭“Printf协议”，使用逐飞二进制协议。按C12，等屏幕底部出现`WAVE:READY`及新客户端连接。
3. 助手清除旧波形，开启自动跟随。按C15起跑，复现异常，C14停车。
4. 保持WAVE连接，等待数据发完，点击助手“保存数据”。文件为JSON格式TXT，可以重新加载查看；尽量保存数据而不只截图。
5. 放大异常前后，比较轮速突升、最终PWM降低及目标速度变化的先后。CH6用于判断真实采样间隔；助手收包时间不能代表控制采样时间。
6. 如需图像，停车并释放两键，再按C13，等待新连接；助手切到“图像传输”。

## 八通道定义

按助手界面从CH0编号至CH7。2026-11-07用户更正实车映射：PWM2模块0左轮、模块1右轮；控制输出和波形共同使用AUTO_MOTOR1_IS_LEFT=0。

| 通道 | 字段 | 单位/来源 |
| --- | --- | --- |
| CH0 | 左电机最终输出占空比 | ‰；1000=100%，左轮M2=C6/C7，PWM2模块0 |
| CH1 | 右电机最终输出占空比 | ‰；右轮M1=C8/C9，PWM2模块1 |
| CH2 | 左轮编码器轮速 | mm/s；按已配置的编码器正方向换算 |
| CH3 | 右轮编码器轮速 | mm/s；停车后仍读取实时编码器 |
| CH4 | 左轮目标速度 | mm/s；本拍控制目标 |
| CH5 | 右轮目标速度 | mm/s；本拍控制目标 |
| CH6 | 本TCP会话相对采样时间 | ms；连接后首次采样为0，重连重新计时 |
| CH7 | 控制状态和故障 | `state + 100 × fault` |

state：0 IDLE、1 STARTING、2 RUNNING、3 FINISHING、4 FINISHED、5 STOPPED、6 FAULT。

fault：0无故障、1配置、4编码器过期、5编码器方向、6硬超速、7堵转、10运行超时、12未就绪。例如606表示FAULT+OVERSPEED，706表示FAULT+STALL。故障定义与当前控制器一致，不新增保护策略。

CH0/CH1是软件写到PWM后端的占空比，不是电压实测；CH2/CH3是编码器轮速，不能单独证明轮胎真实打滑。可暂时隐藏时间/状态或速度通道，再固定Y轴观察PWM细节，保存时保留全部数据。

## 采样和发送边界

- 每10ms PIT依次更新编码器、控制器和电机，再记录同一拍的八个数。PIT不联网、不刷屏。
- 缓存200组，约2秒；满时丢新样本并累计丢点，已记录样本顺序不变。发送缓冲另容纳最多8组。
- 主循环每次poll最多取8组，以官方协议打包，每组36字节，100Hz净数据约3.6KB/s。每次poll最多一次已有的有限SPI事务，模块忙则返回；部分接受只续发剩余后缀。
- 波形发送不等待摄像头新帧。1秒无发送进展时停止本会话采样、丢弃缓存并复位模块，停车后按原5秒回退机制重连。行驶中不建链；网络问题不直接修改PID或电机输出。
- 正常停车或控制故障不关闭波形；持续发送停车后PWM为0及轮速变化。连接故障期间没有完整记录保证。
- 屏幕`S`为本次选择WAVE后驱动接受的完整样本数，不代表电脑确认；`D`为当前TCP采样会话的队列丢点/停用清空数量，重连清零。传输中批次失败另由`E`/网络错误记录，不能用D断言全链路零丢失。重连后建议另存数据，CH6从0重新开始。
