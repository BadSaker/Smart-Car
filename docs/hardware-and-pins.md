摄像头默认采集尺寸188×120，驱动配置在 [zf_device_mt9v03x.h](../car/library/zf_device/zf_device_mt9v03x.h)。本地图像与Wi-Fi SPI参数分别由 [board_config.h](../car/config/board_config.h)、[camera_debug_config.h](../car/config/camera_debug_config.h) 管理，操作见 [逐飞助手指南](seekfree-assistant-debugging.md)。

P6的SPI屏有效针位：2 GND、4 3V3、6 B0/SCL、8 B1/SDA、10 B2/RST、12 C19/DC、14 B3/CS、16 C18/BL。P7：1 B16/RST、2 VCC_5V_EXT、3 GND、4 GND、5 B17/INT、6 D14/MOSI、7 D13/CS、8 D12/SCK、9 NC、10 D15/MISO。按主板手册照片/丝印确认方向，不凭针数判断SPI/并口屏。P2排线朝主板中心，具体相机线序仍需按实物核对。

最终传动关系为编码器齿轮:轮轴转数425:100，1024PPR与STEP×1给出4352计数/轮圈。轮径64mm仅用于名义线速度换算；不用早先同轴同速假设，也不将此比值改称电机减速比。原始计数、符号和速度单位见 [测试指南](motor-encoder-debugging.md)。

## 首次调试配置

`APP_ENABLE_IPS200=1`，默认横屏；电机由独立motor_control模块管理，上电零PWM、完成初始化后C12才可启动10%短时开环测试。原APP_ENABLE_MOTOR_OUTPUT与旧左右引脚别名已移除，避免绕过新按键门控。PIT0每10ms处理电机时序、S3停止与STEP/DIR采样；PIT1保留1ms应用时钟。

Wi-Fi仍是冻结的同步流程，由C13默认关闭；网络等待可推迟屏幕/舵机主循环响应，电机有限时序不依赖主循环。S3电机停止在PIT采样处理，舵机事件锁存后由主循环执行。首轮将轮架空、Wi-Fi保持OFF，验证电机使能、通道和计数方向后再考虑闭环。

## 两路外设电源灯不亮

依据用户指定 [主板手册V1.0](<../参考/RT1064 V3.0主板硬件说明 V1.0.pdf>) PDF29–31页及 [V3.0.1.2原理图](<../参考/RT1064主板V3.0.1.2 原理图.pdf>) 第3–5页：

- 电池经S6控制的Q1进入VCCBAT；U2产生舵机电源，U3/D2产生VCC_5V。
- VCC_5V给核心板5V供电，也进入U4普通3V3、U6 CSI_3V3、U5 5V_EXT开关。
- **U4、U6、U5的EN均受CR控制**；核心板CR经R18/R40连接主板T3。
- CR不是普通GPIO。普通核心板说明书V1.9 PDF21页§10说明，内部DCDC的1.2V经LMV321产生CR约3.3V；Lite手册PDF18页§8.4也明确其不是单片机引脚。CORE灯反映内核电源，不能用B9/IO闪烁替代。
- 电池标称7.4V在主板手册6–12V范围内，但灯亮和标称电压不能代替测量。DAP经SWD提供核心板3.3V，与核心板Type-C供5V不同。

排查顺序（用户手动执行，自动化未测量硬件）：

1. 记录主板普通3.3V、核心板3.3V和CORE灯状态，核对核心板版本丝印。
2. 完全断开电池、DAP USB及核心板USB。断电状态下移除DAP排线和摄像头/屏幕/Wi-Fi，确认核心板方向、对齐、插到底。
3. 仅主板+核心板用电池上电，观察5V、普通3.3V、CSI3.3V、5V_EXT及CORE。仍连USB时关闭主板开关不等于核心板彻底断电。
4. 若仍异常，有万用表且能确认测试点时，直流电压档黑表笔GND，依次测T2/VCC_5V、核心板3V3、核心板CR、主板T3/CR，再测P2 pin1/CSI_3V3、P7 pin2/5V_EXT。避免探针跨接相邻针脚。

| 测量/对照结果 | 定位方向 |
| --- | --- |
| T2明显不是约5V | 输入、S6/Q1、U3/D2及负载 |
| T2约5V，核心板3V3异常 | 核心板插接、稳压或负载 |
| CORE不亮，CR低 | 内核供电或启动时序，先于应用图传 |
| 核心板CR约3.3V，但T3低 | 插接、CR中间连接或下游负载 |
| T2约5V且T3约3.3V，拆掉外设后两输出仍异常 | 主板U5/U6、EN连接或器件问题 |
| 独立电池供电正常，原接法异常 | 再逐项定位DAP上电时序或外设负载 |

用户后续确认：DAP和USB不接、仅电池供电时，摄像头、屏幕和Wi-Fi全部接回后，各电源灯仍全亮。该条件下外设供电已通过用户观察；原异常集中于DAP接入/上电顺序的影响，尚未区分具体机制。当前建议DAP烧录后彻底断电、移除DAP排线，再仅用电池启动图像系统。 未判定器件损坏。核心板版本未确认前不拆焊R18/R40/C19，不强拉CR/EN。原理图未标可更换电源保险丝；启动eFuse不是供电保险丝，本轮不烧写eFuse。

## 接口冲突与版本边界

- 当前使用 CSI 单摄像头；FLEXIO 摄像头使用 C5–C15 等管脚，不能直接叠加到当前电机配置。
- 并口IPS200与Wi-Fi SPI存在复用；本次使用普通IPS200 SPI，SPI3与Wi-Fi SPI1引脚无冲突。
- SDIO 例程涉及 C30 等舵机引脚及多组主板接口，不能直接拼入控制工程。
- 旧普通核心板与 Lite 板的 BOOT、上电时序和保险丝出厂状态不同。没有确认板卡版本前，不按旧说明自动烧写 eFuse。
- 逐飞模板依赖外置 SDRAM。本工程沿用其 Flash 启动后搬移代码到 SDRAM 的布局，需要实际板卡具备匹配硬件。
